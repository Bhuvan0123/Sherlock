# Workload and Capacity Analysis

## Purpose
Give the Team Lead an objective view of how work is distributed across the team.

## When to Use
Use when the Team Lead asks about capacity, workload balance, or who can take on more work.

## Required Inputs
None.

## Data Sources
Facts come from the new shared Core Architecture and Analysis Engine via `skill_execute`.

## Workflow
1. Call `skill_execute` tool with `name="workload-analysis"` and the requested `mode` (brief, verbose, or visual).
2. Relay the exact Markdown returned to the user without summarizing.

## Analysis Rules
All WIQL generation and aggregation rules (>3 count) are handled internally by the `SkillExecutor`.

## Output Format
Relay the exact markdown string generated by `skill_execute`.

## Edge Cases
Missing estimates are handled gracefully.

## Safety Rules
ADO is read-only. No modifications are made.

## Example Requests
- "Analyse the team workload."
- "Who has capacity to take on a new feature?"
