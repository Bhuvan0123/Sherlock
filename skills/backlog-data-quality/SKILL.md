# Backlog Governance and Quality Analysis

## Purpose
Give the Team Lead a broad governance view of the K4K Platform backlog.

## When to Use
Use when the Team Lead asks to analyse backlog quality, governance, or faults.

## Required Inputs
None.

## Data Sources
Facts come from the new shared Core Architecture and Analysis Engine via `skill_execute`.

## Workflow
1. Call `skill_execute` tool with `name="backlog-data-quality"` and the requested `mode` (brief, verbose, or visual).
2. Relay the exact Markdown returned to the user without summarizing.

## Analysis Rules
All WIQL generation and aggregation rules (>3 count) are handled internally by the `SkillExecutor`.

## Output Format
Relay the exact markdown string generated by `skill_execute`.

## Edge Cases
Empty categories are skipped. Categories with >3 items use an ADO query.

## Safety Rules
ADO is read-only. No modifications are made.

## Example Requests
- "Analyse the entire Platform backlog for data quality"
- "Find all faults in the current backlog"
