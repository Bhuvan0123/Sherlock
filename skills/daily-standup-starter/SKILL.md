# Daily Standup Starter

## Purpose
Give the Team Lead a standup-ready table of who is carrying open/active work right now.

## When to Use
Use immediately before or during the daily stand-up.

## Required Inputs
None. Organization, project and team come from server configuration.

## Data Sources
Facts come from the new shared Core Architecture and Analysis Engine via `skill_execute`.

## Workflow
1. Call `skill_execute` tool with `name="daily-standup-starter"` and the requested `mode` (brief, verbose, or visual).
2. Relay the exact Markdown returned to the user without summarizing.

## Analysis Rules
All WIQL generation and aggregation rules (>3 count) are handled internally by the `SkillExecutor`.

## Output Format
Relay the exact markdown string generated by `skill_execute`.

## Edge Cases
Idle members (0 open items) are noted with a 0 count. Overdue and Blocked items > 3 are aggregated into an ADO query.

## Safety Rules
ADO is read-only. No modifications are made.
